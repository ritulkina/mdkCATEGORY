# Контрольная работа. Доска заявок учебного корпуса

В учебном корпусе иногда ломается оборудование или нужно что-то починить в аудитории. Сделайте страницу, на которой сотрудник может добавить заявку, отметить её выполненной и убрать из списка. 

## Исходные данные

Создайте массив `tickets`. Каждая заявка — объект с четырьмя свойствами.

| `title` — что случилось | `room` — где | `category` — категория | `done` — выполнена |
| --- | --- | --- | --- |
| Проектор не включается | 203 | Оборудование | `false` |
| Не закрывается окно | 105 | Аудитория | `false` |
| В коридоре не горит свет | Коридор, 2-й этаж | Другое | `true` |

Храните `title`, `room` и `category` как строки, а `done` как логическое значение. По `done` определяйте, какой статус показать на странице.

## Страница, список и добавление

### 1. Соберите интерфейс

Вверху разместите заголовок «Заявки корпуса». Под ним добавьте два текстовых поля «Что случилось?» и «Где?», выпадающий список «Категория» и кнопку «Добавить заявку». В c и три категории из таблицы.

Под полями оставьте место для сообщений, а ниже добавьте список заявок. Свяжите подписи с полями через `label`, `for` и `id`.

### 2. Покажите заявки из массива

Напишите функцию, которая очищает список на странице и заново выводит заявки из `tickets` (чтото вроде renderGames с прошлого задания).  Для каждой создайте строку через `createElement()` и `append()`. Покажите название, место, категорию и статус «Открыта» или «Выполнена». Текст, который ввёл пользователь, вставляйте через `textContent`.

Вызовите функцию при открытии страницы. Должны появиться все три заявки из таблицы.

### 3. Добавьте новую заявку

При нажатии «Добавить заявку» прочитайте `.value` у двух полей и списка. Если хотя бы одно поле пустое, содержит одни пробелы или категория не выбрана, покажите сообщение рядом с полями. Список при этом не должен меняться.

Если всё заполнено, создайте объект с `done: false`, добавьте его в конец массива через `push()` и обновите список. Очистите текстовые поля и верните `<select>` к пункту «Выберите категорию».

## Действия, фильтр и оформление

### 4. Добавьте кнопки к заявкам

- **«Выполнить».** Показывайте эту кнопку только у открытых заявок. По нажатию меняйте `done` у выбранной заявки на `true` и обновляйте список.
- **«Удалить».** Показывайте кнопку у каждой заявки. По нажатию удаляйте нужный объект из `tickets` через `splice()` и обновляйте список.

### 5. Добавьте фильтр «Только открытые»

Разместите чекбокс над списком. По событию `change` обновляйте список. Если `.checked` равно `true`, показывайте только заявки с `done === false`. При снятии галочки снова покажите все заявки. Проверяйте условие внутри перебора `tickets`, чтобы кнопки продолжали работать с индексами исходного массива.

Если по фильтру ничего не найдено, покажите «Открытых заявок нет». Если сам массив пуст, покажите «Заявок пока нет».

### 6. Оформите страницу

С помощью CSS отделите поля добавления от списка, добавьте отступы между заявками и визуально выделите статусы. Например, статус «Выполнена» можно показать зелёным, а «Открыта» — синим. 

## Дополнительно. Фильтр по категории

Если основная работа готова, добавьте над списком второй `<select>` с пунктом «Все категории» и тремя категориями. При смене категории сразу обновляйте список. Оба фильтра должны действовать вместе. Например, при выборе «Аудитория» и включённой галочке «Только открытые» видны только открытые заявки этой категории. Если в массиве есть заявки, но ни одна не подходит, покажите «Нет заявок по выбранным фильтрам».
